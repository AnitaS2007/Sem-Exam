## Abou GitHub
* For doing the projects in GitHub,we first create an account by Using Email ID of Student.
* Then go to repository and give an appropriate repository name.
* Then click on creating a new file then give a file name.
* Then go to editing the project after editing then click on commit changes.
* The project is saved in our logins and there some changes in the project.
## Collaboration:
* Colloboration is done with project team members.
* When we done a project after first we select one project then go to setting then  click on collaborating
* Enter team member email id when add team member email id if they accept request of colloboration then we get colloborate.
## Documentaton :
* Documentation meaning after doing project we do the report for that project with team members.
